# Echify-App

This repository is a fork of the original team thesis project.

## Project Overview
Echify is a Raspberry Pi-based Dynamic Filipino Sign Language Recognition System that translates sign language into text and speech using AI and computer vision.

## My Contributions
- Raspberry Pi development
- AI model integration
- Computer vision implementation
- Backend integration
- System testing and debugging
